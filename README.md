# 💼 Portfolio Builder

A modern **No-Code Portfolio Builder** that enables users to create a professional developer portfolio without writing any code. Users can fill out a simple form, preview their portfolio in real time, and download it as a standalone HTML website ready for deployment.

---

## ✨ Features

- 📝 Easy-to-use Portfolio Form
- 👀 Live Portfolio Preview
- 📄 One-Click HTML Download
- 🎨 Modern & Responsive Design
- 💻 No Coding Required
- ⚡ Instant Preview Updates
- 📱 Mobile-Friendly Layout
- 🌐 Standalone HTML Export

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/jeeva6347/portfolio-builder.git
```

### Open the Project

Simply open `index.html` in your browser.

Or use **VS Code Live Server**.
